# VTCG
VTCG (Virtual Trading Card Game) is an online-platform that allows users to collect, trade, and display virtual trading cards from popular TCGs. Users can create accounts, open virtual card packs, manager their collections, build decks, and trade cards with other users.

## Features
- Accounts, login, user profiles, accessing collections of cards.
- Card browser using API (https://tcgtracking.com/tcgapi/).
- Click the card to see information using API
- Add cards to Wishlist
- View card collection and detailed card information; quantity owned, filter by rarity, etc. 
- Deck management; create named decks. 
- Trade interface with different users, tradable/untradable, offers. 
- Inventory system; cards/decks linked to user ids.

### Development setup
1. **Clone the repository**
```bash
git clone https://github.com/yourusername/vtcg.git
cd vtcg
```

2. **Install dependencies**
```bash
npm i
```

3. **Start development server**
```bash
npm run start
```
